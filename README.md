# KEY//BREAK — 鍵開けミニゲーム集

Ver.alpha.1.3。ウォークスペースとミニゲーム操作仕様を統合した静的Webアプリです。GitHub Pagesで公開できます。

## 起動

`index.html` をブラウザで直接開く(file://)か、GitHub Pagesでリポジトリのルートを公開してください。
スクリプトはES Modulesではなくクラシックスクリプト(`window.KB` 名前空間)で読み込むため、file:// でも動作します。
読み込み順序は `index.html` 末尾の `<script>` の並びが依存関係です(`main.js` が最後)。読み込み・実行エラーは画面下部に赤帯で表示されます。

## 構成

- `js/core/`: 共通進行、タイマー、難易度、保存、ウォークスペース操作
- `js/modes/`: SINGLE / RANDOM のセッション生成
- `js/games/`: 個別ミニゲーム
- `js/ui/`: 画面遷移
- `css/`: 共通デザイン

## 操作・実装

- ミニゲームの鍵操作は、点線枠で示された WORKSPACE 内でのみ受け付けます。
- ピッキングはカーソル位置からバーの角度を算出し、正解角度でワークスペースをクリックして進行します。
- ピッキングの危険ゲージは0から開始し、固定更新間隔のシミュレーションティックで増減します。
- 振り子ロックはsin関数による往復運動です。成功するたびに解除範囲の位置・速度・振幅をそれぞれ設定範囲内でランダムに変更します。前回値からの最低変化量を設け、速度と振幅は滑らかに目標値へ近づきます。
- 一時停止中は鍵操作・進行処理を停止します。リトライ時は各ゲームの状態を新規生成します。
- 記録はLocalStorageに保存します。

## Ver.alpha.1.1 の変更点

- 振り子ロックの成功時変化を、成功回数の奇数・偶数で交互に変える方式から、しきい値付きランダム方式へ変更しました。
- 解除範囲の位置は針の到達可能範囲内に制限します。
- 速度・振幅・解除範囲位置はそれぞれ独立して再抽選します。

## Ver.alpha.1.3 の変更点

- 画面遷移不具合の原因: `<script type="module">` は file:// で開くとブラウザのCORS制限で `main.js` が読み込めず、ボタンにイベントが登録されなかった。クラシックスクリプトへ移行して解消。
- ピッキングを仕様どおりに再実装(WORKSPACE内操作、危険ゲージ0開始・非数値表示、固定ティック+実時間補正、正解角度の最小角度差45度・最短角度差判定)。
- 振り子ロックの解除範囲の表示幅を判定幅と一致させた。
